2. De ce skillspector auto-verdict NU e semnalul aici

skillspector --no-llm (pattern-only, $0, fără cloud) a dat score 100 / CRITICAL / DO_NOT_INSTALL pe TOATE 4. Asta e artefact de mismatch de tool, nu semnal:

  • skillspector e făcut să scaneze skills (fișiere prompt/markdown mici). Astea 4 sunt harness-uri de agenți — al căror job legitim este file ops, shell, privilege escalation, tool use.
  • Distribuția confirmă: hermes = 8.116 findings non-test (framework Python mare), zero = 286, categoriile top = „Privilege Escalation / Dangerous Code Execution / Tool Misuse" — exact ce face orice framework agentic.
  • OSV.dev CVE lookup a eșuat (fără rețea în sandbox) → fallback static; nu afectează verdictul de pattern.

Semnalul real (per spec §3) = review manual: install/build hooks cu network, citire credentials, telemetrie on-by-default, binare fără sursă. Ăla a trecut 4/4.
